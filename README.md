# 디럭스 청기백기

**플레이:** https://nuclyee72.github.io/BWFlags/

명령을 듣고(하단 자막도 나와요) 그대로 따라 하는 청기백기 게임. 단계가 오를수록 깃발과 특수 물건이 늘어나요.

## 단계

| 단계 | 추가 | 조작 |
| --- | --- | --- |
| 1 | 청기 · 백기 | 깃발 누르기 — 받침대를 축으로 막대가 돌고, 끝까지 돌아야 올려/내려로 판정 |
| 2 | 적기 · 흑기 | "청기 올리지 말고 백기 내려" — 말고 앞의 물건은 그대로 |
| 3 | 위치 명령 | "가장 오른쪽", "왼쪽 두 번째"(어느 쪽에서든 네 번째까지) — 깃발 말고 다른 물건도 불림 · 두 개짜리 명령("청기 올리고 전기 내려") 시작 |
| 4 | 전기 | 스위치 누르기. 내리면 화면 전체가 흑백으로 어두워짐 · 세 개짜리 명령("청기 올리고 백기 내리고 전기 올려") 시작 |
| 5 | 습기 | 가습기 누르기. 올리면 수증기가 화면을 가리며 떠다니다 사라짐 |
| 6 | 고기 | 위 불판 · 아래 접시. 올려: 접시 → 불판으로 끌기, 눌러서 뒤집기(고기 속 색 = 윗면, 테두리 색 = 밑면). 한 면이라도 타면 실패. 양면이 익으면 명령 없이 접시로 내려도 됨(덜 익었으면 실패). 내려: 굽기 상관없이 접시로 |
| 7 | 취기 | 올려: 술병을 술잔에 대서 따르고 술잔 누르기 → 화면이 출렁이고 물건이 제 칸 안에서 위아래로 떠다님(좌우 순서는 그대로). 내려: 물잔 누르기(내려 명령 때만) |

모든 물건은 깃발과 같은 크기로 한 줄에 서고, 명령 3번마다(그리고 새 물건이 나올 때) 자리가 섞여요.
7단계 다음부터는 6번마다 읽는 속도가 빨라지고 유예 시간이 줄어요.

## 판정

- 명령을 다 읽은 순간부터 명령별 유예 시간이 흘러요 (자막 위 막대).
- 모든 물건이 '직전 상태 + 이번 명령'과 같아지면 즉시 성공. 이미 그 상태라면 가만히 있으면 성공이에요.
- 명령 없이 건드린 물건이 있으면 그 명령에서 틀려요. 목숨 3개.

## TTS · 자막

- 브라우저의 Web Speech API(한국어 음성)로 읽어 줘요. 한국어 음성이 없거나 소리를 끄면 자막만 나와요.
- 자막은 한 글자씩 찍히고 음성보다 앞서지 않아요(단어 경계 이벤트가 오면 그 단어 끝에서 기다림). 다 읽고 잠시 뒤 사라져요.

## 실행

빌드 없음. `index.html`을 바로 열거나 아무 정적 서버로:

```sh
python -m http.server 8000
```

UI 토큰과 컴포넌트는 [WMGame](https://github.com/nuclyee72/WMGame)의 `daily-ui.css`(베이지 스타일)를 그대로 써요.
