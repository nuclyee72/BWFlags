# 디럭스 청기백기

**플레이:** https://nuclyee72.github.io/BWFlags/

명령을 듣고(하단 자막도 나와요) 그대로 따라 하는 청기백기 게임.

## 모드

**튜토리얼 (1~7단계)**: 단계마다 방법을 보여 주며 연습해요. 시간 제한 · 점수 · 목숨이 없어요.
명령에 없는 물건을 건드리면 빨갛게, 2.5초 넘게 안 하면 해야 할 물건이 초록으로 빛나요.

| 단계 | 내용 |
| --- | --- |
| 1 | 청기 · 백기 — 깃발을 누르면 받침대를 축으로 막대가 돌고, 끝까지 돌아야 올림/내림 |
| 2 | 적기 · 흑기 · 말고 — "청기 올리지 말고 백기 내려"는 청기 그대로 |
| 3 | 위치 · 같은 색 — "가장 오른쪽", "왼쪽 두 번째"(네 번째까지), "왼쪽 청기" · "청기 전부" |
| 4 | 전기 — 스위치를 내리면 화면이 깜깜해짐 · 자리가 바뀌면 저절로 켜짐 |
| 5 | 습기 — 가습기를 켜면 수증기가 화면을 가림 |
| 6 | 고기 — 접시 → 불판으로 끌기, 눌러 뒤집기, 한 면 5초 익음(반짝) · 10초 탐, 양면 익으면(금빛) 명령 없이 내려도 됨 |
| 7 | 취기 — 술병을 술잔에 대 따르고 술잔 누르기 → 화면이 출렁, 물건이 제 칸 안에서 떠다님 · 내려: 물잔(내려 명령 때만) |

**도전**: 점수 · 목숨 3 · 시간 제한.
- 물건은 최대 7개(특수 물건 2~4개 + 깃발, 같은 색 깃발은 2개까지).
- 명령 3번마다 물건을 새로 뽑고 자리를 섞어요. 빠진 물건의 효과(정전 · 수증기 · 취기 · 굽던 고기)는 사라져요.
- 명령은 최대 3덩어리("백기 내리지 말고 적기 올리고 전기 내려")이고, 6번 맞힐 때마다 레벨이 올라 빨라져요.

## 판정

- 명령을 다 읽은 순간부터 할 일마다 정해진 유예 시간을 더한 만큼 기다려요(자막 위 막대).
- 모든 물건이 '명령 시작 때 상태 + 이번 명령'과 같아지면 즉시 성공. 이미 그 상태라면 가만히 있으면 성공이에요.
- 이번 명령 중에 명령 없이 건드린 물건이 있으면 실패. 이전 명령 뒤에 건드린 건 문제 삼지 않아요.

## TTS · 자막

- 브라우저의 Web Speech API(한국어 음성)로 읽어 줘요. 한국어 음성이 없거나 소리를 끄면 자막만 나와요.
- 자막은 한 글자씩 찍히고 음성보다 앞서지 않아요. 다 읽고 잠시 뒤 사라져요.

## 실행

빌드 없음. `index.html`을 바로 열거나 아무 정적 서버로:

```sh
python -m http.server 8000
```

UI 토큰과 컴포넌트는 [WMGame](https://github.com/nuclyee72/WMGame)의 `daily-ui.css`(베이지 스타일)를 그대로 써요.
